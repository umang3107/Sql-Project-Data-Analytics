# Sql-Project-Data-Analytics
# E-Commerce Sales Analysis using PostgreSQL

## Project Overview
This project analyzes e-commerce sales data using PostgreSQL to identify sales trends, customer behavior, product performance, and profitability insights.

The analysis was performed on the Superstore dataset containing 9,994 transactional records.

---
## Dataset

Superstore Sales Dataset containing 9,994 retail transactions including:
- Sales
- Profit
- Customers
- Regions
- Categories
- Discounts

Dataset Source:
https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Tools Used
- PostgreSQL
- pgAdmin
- VS Code

---

## SQL Concepts Used
- GROUP BY
- HAVING
- Aggregate Functions
- CASE Statements
- Window Functions
- CTEs (Common Table Expressions)
- Date Functions
- Subqueries

---

## Business Problems Solved
- Identified top-selling products
- Analyzed regional sales performance
- Detected loss-making products
- Segmented customers based on spending
- Evaluated profitability trends
- Ranked customers region-wise

---

## Key Insights

### Sales Insights
- Technology category generated the highest sales revenue.
- West region contributed the highest overall sales.

### Profitability Insights
- Some products generated negative profit despite high sales.
- Higher discounts were associated with lower profitability.

### Customer Insights
- Premium customers contributed major revenue share.
